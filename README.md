# PAAS Qwen3-VL

Experimental training and evaluation utilities for applying Qwen3-VL models to
face-forgery detection workflows built around MIDS and AxonLabs datasets.

The project contains dataset-building scripts, fine-tuning and evaluation
launchers, label-generation utilities, prompt templates, and lightweight
configuration files.

## Repository policy

Only source code, configuration, and documentation are versioned. Model
weights, datasets, virtual environments, caches, and generated results are kept
out of Git because they are large or reproducible local artifacts.
